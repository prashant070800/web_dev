# Study Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a public, cross-linked interview-prep hub at `hellops.in/study/`, with one Markdown page per project, role, and technology.

**Architecture:** GitHub Pages already runs Jekyll on this repo. We add three Jekyll collections (`_projects`, `_experience`, `_tech`) rendered by one shared layout. Cross-links come from front matter tags through two includes, so nothing is linked by hand. The portfolio `index.html` has no front matter and passes through the build byte-for-byte. A Python checker (`tools/check_site.py`) inspects the built `_site/` and is the test suite for every task.

**Tech Stack:** Jekyll 3.10 via the `github-pages` gem (run in Docker, `ruby:3.3`), Liquid, kramdown Markdown, plain CSS, Python 3 stdlib for the checker.

**Spec:** `docs/superpowers/specs/2026-10-12-study-hub-design.md`

## Global Constraints

- Every page is public. Write-ups describe how things work in general terms, with no private endpoints, client names, credentials, or proprietary internals.
- Use no new CSS colors. `study.css` uses only the `var(--…)` tokens defined in `:root` of `style.css`.
- `index.html` must stay without front matter. `_site/index.html` must be byte-identical to it.
- Never add `id` attributes to `<section>` elements on study pages. `script.js` scroll-spies `main section[id]`, and an id there would steal the active state from the Study nav link.
- Permalinks: `/study/projects/<slug>/`, `/study/experience/<slug>/`, `/study/tech/<slug>/`, where `<slug>` is the filename without `.md`.
- Quote every `q:` value in YAML, because questions often contain colons.
- Commit messages end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A tag with no page yet** (e.g. `exotel`) renders as dashed plain text, never as a dead link. Tested in Task 2 (`tag-missing` text, plus a forbidden link to `/study/tech/exotel/`).
2. **A tech page that nothing is tagged with** shows "Nothing is tagged with this yet." instead of an empty Related block. Tested in Task 3 (fixture) and Task 4 (`redis`).
3. **A tech page with a missing or unknown `category`** still appears on the hub, under "Other". Tested in Task 3 (fixture with no category; the hub-completeness check fails if it's dropped).
4. **A page with no `questions`** renders no "Interview questions" heading and no count on its hub card. Tested in Task 3 (fixture) through `FORBIDDEN_TEXT`.
5. **A project with no `experience`** (`vargi-bot`) renders no "Built during" block. Tested in Task 4 through `FORBIDDEN_TEXT`.

`tools/check_site.py`:
```python
"""Checks the built site in _site/ against the study hub spec.

Run after a Jekyll build (tools/build-site.ps1 does both):
    python tools/check_site.py
Exits non-zero and lists every problem found.
"""
import re
import sys
import xml.etree.ElementTree as ET
from html.parser import HTMLParser
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
SITE = ROOT / "_site"
COLLECTIONS = ("projects", "experience", "tech")

# Repo-only files that must never be published
MUST_BE_ABSENT = [
    "CLAUDE.md", "CLAUDE.html", "README.md", "README.html", "resume.tex",
    "build-resume.ps1", "docs", "tools", "Gemfile", "Gemfile.lock", ".githooks",
]
MUST_BE_PRESENT = [
    "index.html", "style.css", "script.js", "resume.pdf", "CNAME", "robots.txt",
    "sitemap.xml", "images/prashant.jpg",
]

# Hub and sitemap must list every study page (switched on once the hub exists)
CHECK_HUB = False

# (page under _site, href that must appear on it)
REQUIRED_LINKS = []
# (page under _site, href that must not appear on it)
FORBIDDEN_LINKS = []
# (page under _site, text that must appear in its HTML)
REQUIRED_TEXT = []
# (page under _site, text that must not appear in its HTML)
FORBIDDEN_TEXT = []

EXTERNAL = re.compile(r"^(?:[a-z][a-z0-9+.-]*:|//|#)", re.I)


class RefCollector(HTMLParser):
    def __init__(self):
        super().__init__()
        self.refs = []

    def handle_starttag(self, tag, attrs):
        for name, value in attrs:
            if name in ("href", "src") and value:
                self.refs.append(value)


def refs(page):
    collector = RefCollector()
    collector.feed(page.read_text(encoding="utf-8"))
    return collector.refs


def html(rel):
    page = SITE / rel
    return page.read_text(encoding="utf-8") if page.exists() else None


def resolve(page, ref):
    """Map an internal href/src to the file it points at under _site, or None if external."""
    if EXTERNAL.match(ref):
        return None
    path = ref.split("#")[0].split("?")[0]
    target = SITE / path.lstrip("/") if path.startswith("/") else page.parent / path
    if path.endswith("/") or target.is_dir():
        target = target / "index.html"
    return target


def question_count(source):
    front_matter = source.read_text(encoding="utf-8").split("---")[1]
    return len(re.findall(r"^\s*- q:", front_matter, re.M))


def main():
    if not SITE.is_dir():
        print("No _site/ found: build the site first (tools/build-site.ps1).")
        return 1
    errors = []

    for rel in MUST_BE_ABSENT:
        if (SITE / rel).exists():
            errors.append(f"published but must not be: {rel}")
    for rel in MUST_BE_PRESENT:
        if not (SITE / rel).exists():
            errors.append(f"missing from build: {rel}")
    built_index = SITE / "index.html"
    if built_index.exists() and built_index.read_bytes() != (ROOT / "index.html").read_bytes():
        errors.append("index.html was changed by the build (it must pass through untouched)")

    hub = SITE / "study" / "index.html"
    hub_refs = refs(hub) if CHECK_HUB and hub.exists() else []
    sitemap = html("sitemap.xml") or ""
    for coll in COLLECTIONS:
        for source in sorted((ROOT / f"_{coll}").glob("*.md")):
            url = f"/study/{coll}/{source.stem}/"
            page = SITE / url.strip("/") / "index.html"
            if not page.exists():
                errors.append(f"no page built for _{coll}/{source.name}")
                continue
            want = question_count(source)
            got = page.read_text(encoding="utf-8").count('<details class="qa"')
            if got != want:
                errors.append(f"{url}: {got} questions rendered, front matter has {want}")
            if CHECK_HUB:
                if url not in hub_refs:
                    errors.append(f"hub does not link to {url}")
                if f"<loc>https://hellops.in{url}</loc>" not in sitemap:
                    errors.append(f"sitemap does not list {url}")

    for page in sorted(SITE.rglob("*.html")):
        for ref in refs(page):
            target = resolve(page, ref)
            if target is not None and not target.exists():
                errors.append(f"{page.relative_to(SITE).as_posix()}: broken link {ref}")

    try:
        ET.parse(SITE / "sitemap.xml")
    except (ET.ParseError, FileNotFoundError) as e:
        errors.append(f"sitemap.xml is not valid XML: {e}")

    for rel, href in REQUIRED_LINKS:
        if html(rel) is None or href not in refs(SITE / rel):
            errors.append(f"{rel}: missing link {href}")
    for rel, href in FORBIDDEN_LINKS:
        if html(rel) is not None and href in refs(SITE / rel):
            errors.append(f"{rel}: must not link {href}")
    for rel, text in REQUIRED_TEXT:
        if text not in (html(rel) or ""):
            errors.append(f"{rel}: missing text {text!r}")
    for rel, text in FORBIDDEN_TEXT:
        if text in (html(rel) or ""):
            errors.append(f"{rel}: must not contain {text!r}")

    for error in errors:
        print("FAIL", error)
    print(f"{len(errors)} problem(s)" if errors else "OK: site matches the study hub spec")
    return 1 if errors else 0


if __name__ == "__main__":
    sys.exit(main())
```

# Builds the site exactly like GitHub Pages (github-pages gem in Docker) into _site/, then checks it.
# Usage: powershell -ExecutionPolicy Bypass -File tools/build-site.ps1 [-Serve]

$ErrorActionPreference = 'Stop'

Set-Location $root

if ($LASTEXITCODE -ne 0) { throw 'Jekyll build failed' }

python tools/check_site.py
if ($LASTEXITCODE -ne 0) { throw 'Site check failed' }

if ($Serve) { python -m http.server 8000 --directory _site }
