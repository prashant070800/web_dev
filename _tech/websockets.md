title: WebSockets
category: realtime
summary: Full-duplex connections for realtime data.
questions:
  - q: "How is a WebSocket different from HTTP polling?"
    a: |
      After one HTTP upgrade handshake, a WebSocket keeps a single TCP connection open,
      and both sides can send messages at any time. Polling opens repeated requests and
      adds latency and overhead between updates.
