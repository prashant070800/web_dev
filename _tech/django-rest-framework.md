questions:
  - q: "What is the difference between a Serializer and a ModelSerializer?"
    a: |
      A `Serializer` declares every field and its create/update logic by hand. A
      `ModelSerializer` generates fields and validators from a model and provides default
      `create()` and `update()`, so it needs far less code for model-backed endpoints.
